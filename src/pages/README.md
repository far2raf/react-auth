# React Authentication with GraphQL

This is a simple but complete client-side React application that demonstrates a modern authentication flow.

## Getting Started
Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites
- **Node.js** (v22.17.0 is used for this project, see `.nvmrc`)

### Installation & Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev 
   ```
   The application will be available at http://localhost:5173 (or another port if 5173 is busy).


### Tests

1. **Run the test pack:**
    ```bash
    npm run test 
    ```
